# Final Paper Code for CSC133 - Modelling and Simulation

This repository holds the code of the computational framework for comparing mangrove species for the research paper titled "**A One-Dimensional Drag-Based Computational Framework for Wave Attenuation Across Mangrove
Species**."

This is for complying the final requirements for the subject **CSC133 - Modelling and Simulation**.
